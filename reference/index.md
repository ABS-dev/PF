# Package index

## Exported Functions

- [`IDRlsi()`](https://abs-dev.github.io/PF/reference/IDRlsi.md) : IDR
  likelihood support interval.
- [`IDRsc()`](https://abs-dev.github.io/PF/reference/IDRsc.md) : IDR
  confidence interval.
- [`RRlsi()`](https://abs-dev.github.io/PF/reference/RRlsi.md) : RR
  likelihood support interval.
- [`RRmh()`](https://abs-dev.github.io/PF/reference/RRmh.md) :
  Mantel-Haenszel method, CI for common RR over strata or clusters with
  sparse data.
- [`RRmpWald()`](https://abs-dev.github.io/PF/reference/RRmpWald.md) :
  Wald confidence intervals for RR from matched pairs
- [`RRor()`](https://abs-dev.github.io/PF/reference/RRor.md) : RR
  estimate from logistic regression.
- [`RRotsst()`](https://abs-dev.github.io/PF/reference/RRotsst.md) : RR
  exact CI, OTSST method.
- [`RRsc()`](https://abs-dev.github.io/PF/reference/RRsc.md) : RR score
  based asymptotic CI.
- [`RRstr()`](https://abs-dev.github.io/PF/reference/RRstr.md) :
  Gart-Nam method, CI for common RR over strata or clusters.
- [`RRtosst()`](https://abs-dev.github.io/PF/reference/RRtosst.md) : RR
  exact CI, TOSST method.
- [`phiWt()`](https://abs-dev.github.io/PF/reference/phiWt.md) :
  Binomial dispersion parameter.
- [`rsb()`](https://abs-dev.github.io/PF/reference/rsb.md) : Rao-Scott
  weights.
- [`rsbWt()`](https://abs-dev.github.io/PF/reference/rsbWt.md) :
  Rao-Scott weighting.
- [`tauWt()`](https://abs-dev.github.io/PF/reference/tauWt.md) :
  Binomial dispersion: intra-cluster correlation parameter.
- [`.rr.score.asymp()`](https://abs-dev.github.io/PF/reference/dot-rr.score.asymp.md)
  : Internal function.
