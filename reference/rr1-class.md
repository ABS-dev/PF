# Data class rr1

Data class rr1

## Fields

- `estimate`: vector with point and interval estimate

- `estimator`: either `"PF"` or `"IDR"`

- `Y`: data.frame with restructured input

- `rnd`: how many digits to round display

- `alpha`: complement of c.i.
